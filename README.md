## The Story

**Growth thesis:** FinWise's growth leaks because users never experience value tied to a real decision. Onboarding that delivers a decision-linked forecast, shared with the accountant, lifts conversion and retention and turns each accountant into a multiplier who brings in new businesses without ad spend.

- **One friction.** The metric I needed didn't exist in the data. FinWise only tracked feature activity, which had doubled without moving conversion, so I had to define a new value metric (a decision answered) and accept that it can only be validated once it's tracked.
- **One Aha.** The product doesn't have to wait for the user. Spanish tax deadlines hit every SMB at the same time, so FinWise can trigger value itself: a reason to return, a moment to involve the accountant, and an upgrade moment in one.
- **Takeaways.**
  1. **Giving structure to what I've been doing for years.** Experimentation has helped me apply the scientific method to product decisions I've been making throughout my career. It provides a clear framework to move from intuition and observations to hypotheses, measurable outcomes and evidence-based decisions.
  2. **Experimentation must start with customer value.** For me, experimentation only makes sense when it's connected to the value we create for customers. Improving a metric is not necessarily improving a product. The real question is whether a change helps customers achieve something meaningful and ultimately creates sustainable business value.
  3. **A hypothesis doesn't need to be right for an experiment to succeed.** This is probably one of my biggest takeaways. An experiment isn't designed to confirm what we believe. It's designed to challenge our assumptions. Discovering that a hypothesis is wrong is still progress because it helps us eliminate uncertainty and make better decisions.
  4. **Good experimentation requires discipline.** Choosing the right method, defining success criteria, guardrails and measurement windows before launching, and distinguishing statistical significance from business impact are essential to producing results we can trust.
  5. **Experimentation is a continuous learning system, not a one-off test.** The real value comes from connecting insights across the product lifecycle, from activation and retention to monetization and growth. Each experiment informs the next, helping us build better products rather than simply deliver more features.
